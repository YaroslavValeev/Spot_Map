# Client Convenience Checklist v1

**Статус:** принято вместе с ADR-004 (2026-11-19)  
**Назначение:** 10 справедливых пунктов удобства для райдера. Это **не** второй рейтинг и не замена SpotScore. Пункты питают домены формулы и показываются в карточке как наличие факта (`yes` / `no` / `unknown` / `unsupported`).

| # | key | Подпись для UI | Домен SpotScore | Примечание |
|---:|---|---|---|---|
| 1 | `booking_contact` | Удобная запись и связь | `service` | телефон / мессенджер / онлайн-запись |
| 2 | `pricing_clarity` | Понятные цены / длительность сета | `value` | прайс на сайте или у клуба |
| 3 | `parking_access` | Парковка и подъезд | `infrastructure` | |
| 4 | `changing_facilities` | Раздевалки / душ / туалет | `infrastructure` | |
| 5 | `gear_rental` | Прокат досок и жилетов | `equipment` | |
| 6 | `coaching_available` | Инструктор / обучение новичков | `coaching` | |
| 7 | `safety_basics` | Безопасность (брифинг, жилет, правила) | `safety` | |
| 8 | `riding_quality` | Качество волны / трассы под уровень | `riding_conditions` или `course_setup` | зависит от дисциплины |
| 9 | `guest_comfort` | Зона ожидания / кафе / комфорт семьи | `infrastructure` + `service` | |
| 10 | `hours_freshness` | Актуальность сезона / часы работы | Freshness (отдельно) | не входит в балл качества |

## Правила UI

- Пока SpotScore не готов: блок рейтинга = «Появится позже».
- Чеклист: `unknown` по умолчанию; `yes`/`no` только с `source` / `evidence_note` / `observed_at`.
- `unsupported` — пункт неприменим к типу объекта (например cable-only без катера).
- Платное продвижение не меняет факты и не заполняет чеклист автоматически.
