# SpotMap — Cable Installation Passport v1.0

**Новый обязательный P0-паспорт для дисциплины «Вейкборд — электротяга»**  
**Дата:** 11.11.2026 · **Статус:** канон данных и UX для всех локаций с установками.

## 1. Бизнес-требование

SpotMap должен представлять **все выявленные места с установками электротяги** как отдельный предмет поиска, независимо от известности клуба, наличия сайта или активности Telegram. В каждой подтверждённой локации есть `Spot`, а каждая отдельная установка — `Cable Installation`. Если на одной площадке 4 установки, система должна уметь отобразить **4 установки**, не дублируя клуб или площадку.

**Не утверждать, что все установки в России уже найдены.** Метрика полноты строится как coverage аудируемых источников/регионов, а не как несуществующий «общий процент от абсолютного количества».

## 2. Разновидности, которые различает система

| Code | Название в интерфейсе | Особенности |
|---|---|---|
| `full_size_circuit` | Кольцевая / полноразмерная | замкнутая трасса, несколько райдеров (если подтверждено) |
| `two_tower_reversible` | Двухопорная / реверсивная | поездка между двумя опорами, возможна смена направления |
| `multi_tower_other` | Другая многoопорная | количество опор подтверждается по источнику |
| `pool_cable` | Крытая / бассейн | отдельные условия и требования доступа |
| `portable_other` | Переносная / мобильная | может менять расположение, нужна история установок |
| `unknown` | Тип уточняется | публикуется только с честной маркировкой |

Если тип не подтверждён, **не присваивать `two_tower_reversible` автоматически** по словам «канатка» или «лебёдка».

## 3. Структура паспорта (P0)

| Блок | Поля | Минимум публикации / проверка |
|---|---|---|
| Идентичность | `installation_id`, spot_id, локальное имя/номер | обязательные ID |
| Гео | собственная точка, accuracy, источник, дата проверки | **verified** для map pin |
| Тип установки | enum из п.2 | `unknown` допускается, но фильтр «кольцевая/реверс» требует доказательства |
| Оператор | club_id nullable | клуб может отсутствовать/быть неясен |
| Технические | производитель, модель, год, число опор, длина трассы, высота троса, min/max скорость | `null` без первоисточника |
| Направление | CW / CCW / reversible / bidirectional / unknown | не путать «в обе стороны» и реверс |
| Одновременность | число держателей, одновременных райдеров | условия зависят от установки |
| Трасса | объект LineString/Polygon (optional), старт/финиш | уточнение, нельзя рисовать из головы |
| Фигуры | каждая фигура с id, типом, уровнем, статусом, местом | отделить «есть фигуры» от точного списка |
| Тренировки | уровни, обучающие режимы, тренер, детские занятия | проверить наличие |
| Оборудование | прокат доски, шлем/жилет, гидрокостюм | nullable |
| Прайс | сет / час / группа / абонемент, валюта/сезон | только с valid interval |
| График | дни/сезон, indoor зимой, особые ограничения | статус работы + verified_at |
| Условия | ветровая защищённость, глубина, препятствия на акватории | из Spot/локального источника |
| Сервис | душ, раздевалка, парковка, кафе, дети | при наличии доказательств |
| Контакты | телефон/сайт/соцсети | реальные адреса |
| Trust | source IDs, verified_at, Confidence, Freshness | независимы от SpotScore |
| Safety | требования к жилету/шлему, briefing, rescue coverage, incidents, restricted mode | никогда не придумывать сертификацию |

## 4. Фигуры и спортивная конфигурация

Для каждой `installation_features`:

```yaml
feature_id: uuid
installation_id: uuid
kind: kicker | box | rail | slider | pipe | funbox | other
name: string|null
side_or_segment: string|null
usable_direction: clockwise | counterclockwise | both | unknown
skill_level: beginner | intermediate | advanced | pro | unknown
status: active | removed | damaged | unknown
source_ids: [uuid]
last_verified_at: timestamp|null
```

**Отличие от вейксёрфинга:** оборудование катера не является атрибутом `Cable Installation`. Настройки волны, ballast, regular/goofy — в `boats`; кабельная установка имеет track, towers, speed, features, route geometry, access/safety.

## 5. UX на карте

- Фильтр дисциплины: **«Вейкборд — электротяга»**.
- Подфильтры: «Все установки», «Кольцевая», «Реверсивная», «Крытая», «С фигурами», «Новичкам», «Открыто/сезон закрыт/неизвестно».
- Маркер установки: отдельная простая иконка кабеля; число установок в кластере.
- Масштаб площадки: если установки географически рядом, показывать **offset/spiderfy**/список, но не терять отдельные IDs.
- Карточка preview: название установки, тип, статус, количество фигур (если известно), SpotScore (если рассчитан), цена, CTA.
- На детальном Spot: вкладка **«Установки (N)»**; N = количество установок в реестре, рядом пометка сколько подтверждены.
- При клике на одну установку открывается её паспорт, а не общий рейтинг парка.

### Типовые состояния

```text
Электротяга · Реверсивная №2
Местоположение подтверждено ✓
Сезон 2026: статус неизвестен ⚠
Фигуры: 3 (последняя проверка 31 день назад)
[Маршрут к площадке] [Контакты оператора]
[Проверить информацию] [Добавить обновление]
```

## 6. Политика карты для всех локаций

Публичный режим «Все» отображает **все геоподтверждённые установки**, включая сезонно закрытые, с явными статусами. Скрытые за ошибочной геопривязкой объекты не показываются как ложные пины. Установки без координат включаются в **каталог-кандидат**, куда пользователь/модератор может прислать геодоказательство. `permanently_closed` доступны в «История/архив», но по умолчанию не предлагаются для катания.

**Цели P0 data QA:**
- 100% найденных кабельных кандидатов проходит staging и имеет задачу геопроверки;
- 100% geo-verified установок показаны при фильтре «Все» (кроме скрытых/дублей);
- 0 установок без verified location получают выдуманный пин;
- 0 ложных слияний отдельных установок;
- 0 тарифов прошлых сезонов представлены текущими.

## 7. Источники discovery — не ограничиваться каталогами

- открытые реестры cable-парков и официальные карты федераций;
- страницы и геометки клубов;
- региональные Telegram/VK сообществa;
- локальные сайты парков и спортивных школ;
- каталоги проката и соревнований;
- результаты соревнований с местом проведения;
- отзывы и фото (если разрешена обработка и публикация);
- запросы на Claim и UGC-предложения;
- официальный контакт для проверки типа/количества/статуса.

Информация проходит `source → staging → alias check → geo verify → installation(s) → publish`. Разделять `кандидат клуба` и `кандидат установки`; число парков не равно числу лебёдок.

## 8. Первая проверка по MyWave Wake Intelligence V2

В приложенном источнике обнаружены следующие записи с признаками электротяги: WakeHome, WakeStyle Spot (Крылатское), WAKESTYLE «Энигма», Flat Wake Park, Reef Surf Club, Wakesummer Park. У WakeStyle Spot в описании отдельно упомянуты **три реверсивные установки**, но до отдельной гео- и операционной проверки эта цифра — **кандидатное утверждение источника**, не три автоматически опубликованных пина.

**Внимание:** этот стартовый список из пользовательского файла не является полным реестром всех кабельных установок России. План — отдельная картографическая инвентаризация электротяги с региональным покрытием.

## 9. Меры доверия и безопасности

- Иконка `✓` относится к тому, **что именно проверено**: координаты, тип, работа, цена, а не к «100% безопасно».
- Повреждённые фигуры помечать отдельно; если риск подтверждён, функциональность рекомендации/записи ограничивать.
- Для спортивных мероприятий ссылаться на актуальные IWWF правила и индивидуальные требования, **не распространять соревновательные нормы на все рекреационные установки автоматически**.
- Утверждения об обязательных шлемах/жилетах брать из правил оператора и нормативных источников, а не домысливать.
- Контент пользователей не должен включать персональные данные детей без права публикации.

## 10. Acceptance Criteria

- [ ] На площадке с тремя проверенными установками создаются три отдельных `installation_id` и три маркера/элемента списка.
- [ ] Фильтр «Кольцевая» не выбирает реверсивную по ошибке.
- [ ] Фильтр «Крытая» работает по отдельному признаку, не только по типу «pool».
- [ ] Одинаковый Telegram-канал двух площадок не объединяет установки.
- [ ] Для каждой фигуры есть индивидуальный статус и источник.
- [ ] Нет координат → нет маркера; есть запись в очереди.
- [ ] Сезонно закрыто ≠ навсегда закрыто.
- [ ] Катерный вейкборд никогда не отображается как электротяга.
- [ ] Нет SpotScore → «Пока нет оценки», не `0/100`.
- [ ] Из любой карточки установки пользователь может открыть её Spot/Club и наоборот.
