## Часть В. Бесплатный ключ Яндекс.Карт (это НЕ Погода)

Нужен только чтобы **карта** открывалась. Это не тайлы ветра.

### Ссылки

1. Кабинет: https://developer.tech.yandex.ru/  
2. Продукт JS API: https://yandex.ru/maps-api/products/js-api  
3. Условия бесплатно: https://yandex.ru/dev/commercial/doc/ru/  
4. Legal / лимиты: https://yandex.ru/legal/maps_api/ru/  

### Шаги

1. Откройте https://developer.tech.yandex.ru/  
2. Войдите своим Яндекс ID.  
3. Подключите **JavaScript API и HTTP Геокодер**.  
4. Примите условия **бесплатного** использования.  
5. Скопируйте ключ.  
6. В кабинете ограничьте ключ по HTTP Referer:  
   - `http://127.0.0.1:*`  
   - `http://localhost:*`  
   - ваш будущий домен (если есть)  
7. Откройте файл `services/api/.env` в Блокноте.  
8. Найдите строку `YANDEX_MAPS_API_KEY=` и вставьте ключ после `=`.  
9. Сохраните файл.  
10. Перезапустите API (терминал с uvicorn → Ctrl+C → снова `python -m uvicorn app.main:app --host 127.0.0.1 --port 18080`).  
11. Обновите http://127.0.0.1:18080/ с `Ctrl+F5`.

### Чего НЕ делать

- Не покупать «Яндекс Погоду для бизнеса».  
- Не заполнять `YANDEX_WEATHER_TILE_KEY` (это платный слой ветра).  
- Документация платных тайлов (только чтобы знать, что это не наш путь):  
  https://yandex.ru/dev/weather/doc/ru/concepts/tiles  
  https://yandex.ru/dev/weather/doc/ru/concepts/pricing

### Что вы говорите агенту

Одну строку контакта, например:

```text
User-Agent контакт: SpotMap https://mywavewake.ru y.valeev@gmail.com
```

### Что напишет сайт пользователю (сделает разработчик)

«Погода: MET Norway» + ссылка на лицензию.  
Если MET недоступен — запасной Open-Meteo.

### Проверка руками (после внедрения)

Вставьте в браузер (с сервера будет User-Agent; в браузере напрямую MET может ответить 403 — это нормально):

```text
http://127.0.0.1:18080/v1/weather/point?lat=55.80&lon=37.36
```

Должны быть воздух, ветер, направление, порывы.  
Вода: «нет измерений», если вы сами её не внесли.

## Часть Д. Слой ветра на карте — бесплатные варианты (выберите один)

Платный путь Яндекс Погоды **закрыт**.

| Буква | Что увидит пользователь | Ваши действия сейчас |
|---|---|---|
| **A** | Кнопка «Ветер» рисует стрелки по карте из бесплатного прогноза | Написать агенту: `Выбираю A` |
| **B** | Стрелка ветра только у открытого спота | Написать: `Выбираю B` |
| **C** | Кнопка есть, честно «слой недоступен» | Написать: `Выбираю C` (самый быстрый) |

Рекомендация при «только бесплатно и быстрее»: сначала **C**, потом **B**, потом **A**.

## Часть Е. Ветровой профиль спота (вручную, 0 ₽)

Без этого оценка катания всегда «Не оценено» — так и должно быть.

### Файлы

- Шаблон: `config/wind_profiles/wind_profile_TEMPLATE.json`  
- Правила: `reference/weather/spotmap_wind.py`  

### Шаги «как для ребёнка»

1. Откройте карту http://127.0.0.1:18080/  
2. Кликните знакомый спот (например Мякинино или Take&Wake).  
3. Скопируйте его UUID (из адреса API карточки или попросите агента: «дай spot_id для …»).  
4. Скопируйте шаблон в новый файл, например:  
   `config/wind_profiles/myakinino_ring.json`  
5. Заполните секторы ветра **откуда дует** (0 = север, 90 = восток):

```json
{
  "spot_id": "ВСТАВЬТЕ-UUID",
  "discipline_id": "cable_ring",
  "approved": false,
  "version": "draft-1",
  "north_convention": "METEOROLOGICAL_FROM_DEGREES",
  "sectors": [
    {
      "from_deg": 0,
      "to_deg": 90,
      "verdict": "good",
      "max_wind_mps": 8,
      "max_gust_mps": 12,
      "note": "Восточный сектор — комфортно"
    },
    {
      "from_deg": 91,
      "to_deg": 359,
      "verdict": "limited",
      "max_wind_mps": 5,
      "max_gust_mps": 8,
      "note": "Остальные направления"
    }
  ],
  "notes": "Ручная оценка Ярослава",
  "verified_by": "Yaroslav"
}
```

6. Секторы **не должны пересекаться**.  
7. Пока сомневаетесь: `"approved": false`.  
8. Когда уверены: `"approved": true`.  
9. Попросите агента: «внеси этот профиль в БД approved» (или вставьте SQL сами — агент даст готовую команду).  
10. Обновите карточку спота — должна появиться оценка, не «Не оценено».

**Нельзя:** копировать один профиль на все соседние клубы.

## Часть Ж. Температура воды (только измерение, 0 ₽)

1. Нельзя подставлять температуру воздуха.  
2. Если нет замера — на сайте будет «Нет данных» / «нет измерений».

```text

```

4. Агент занесёт в `water_temperature_observations` (после появления формы модерации — сможете сами).

## Часть З. Подтверждённые записи (без платного webhook)

Клик «Записаться» **не** считается бронью.

Выберите один бесплатный способ:

### Вариант 1 — Telegram (самый простой)

1. Договоритесь с клубом: раз в неделю пишут `@MyWave23` число записей с SpotMap.  
2. Вы записываете число в таблицу.

### Вариант 2 — Google Форма (бесплатно)

1. Откройте https://forms.google.com/  
2. Создайте форму: дата / спот / «запись подтверждена» / код `SPOTMAP`.  
3. Отдайте ссылку клубу.  
4. Ответы смотрите в Google Таблице: https://sheets.google.com/

### Вариант 3 — промокод

1. Код `SPOTMAP` при записи у клуба.  
2. Клуб считает такие записи и присылает итог.
