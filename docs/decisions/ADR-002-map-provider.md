# ADR-002 — Картографический провайдер

**Статус:** принято временно (2026-11-12)  
**Контекст:** карта нужна в Sprint 01 Exit, но юридический режим и квоты ещё не подтверждены.

## Решение

1. Backend отдаёт GeoJSON / bbox API — **провайдер-агностично**.
2. Frontend (когда появится) подключает провайдер через адаптер (`MapAdapter`), без хардкода SDK в домене.
3. Кандидаты: Яндекс Карты (виджет/JS), MapLibre + OSM tiles, Google Maps — выбор только после проверки лицензии и attribution.
4. До выбора провайдера публичная карта может показывать **пустое состояние** + счётчик staging, если нет geo-verified точек.

## Не делаем сейчас

- Не хардкодим API-ключи.
- Не публикуем пины без `geo_status=verified`.
