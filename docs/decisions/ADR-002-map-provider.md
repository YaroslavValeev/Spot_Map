# ADR-002 — Картографический провайдер

**Статус:** принято (обновлено 2026-11-14)  
**Контекст:** нужен UI карты для России без OSM/Leaflet-подложки.

## Решение

1. **UI MVP: Яндекс.Карты JS API 2.1** (`lang=ru_RU`).
2. Backend по-прежнему отдаёт GeoJSON провайдер-агностично (`/v1/map/points`).
3. Ключ `YANDEX_MAPS_API_KEY` хранится в `.env` (не в Git); в браузер отдаётся через `/v1/config/public` и ограничивается HTTP-referrer в кабинете Яндекса.
4. Обзор карты ограничен приблизительными границами России (`restrictMapArea`).
5. Пины только `published` + `geo_status=verified`.

## Не используем в UI

- OpenStreetMap tiles
- Leaflet как подложку карты
- Google Maps

## Замена позже

Провайдер остаётся сменным на уровне адаптера UI; домен/API не зависят от Яндекса.
