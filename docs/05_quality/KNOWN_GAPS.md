# Открытые вопросы и ограничения (11.11.2026)

1. В пакете **нет исходников веб-приложения SpotMap**; только reference scorer. Нельзя утверждать, что frontend/API уже существуют.
2. SQL — стартовая проектная схема; не применялась к реальной PostgreSQL/PostGIS. Требуются миграции, FK/RLS-аудит и integration tests.
3. Staging: 80 записей-кандидатов, из них шесть с cable-признаками. Координаты и доступность не подтверждены. Эти шесть — не число реальных установок.
4. Пример паспорта синтетический и не должен попасть в production seed.
5. Формула SpotScore — reference implementation; пока не валидирована на достаточном количестве независимых реальных наблюдений.
6. Установка, парк, оператор и клуб могут иметь разные жизненные циклы. Обязательно моделировать их независимо.
7. Для geocoding, tiles, weather и навигации нужно выбрать провайдера и изучить лицензии/квоты.
8. Доступ к частным исходникам и персональной информации ограничить; публичный GitHub не должен содержать raw dataset.
