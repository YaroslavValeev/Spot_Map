## Чего нельзя утверждать на основании этих файлов

- «Все установки электротяги России уже найдены» — это задача будущего OSINT-охвата, а не доказанный факт.
- «Все 80 объектов действуют в 2026» — нет подтверждённой актуальности.
- «У всех 80 объектов есть точные координаты» — координаты отсутствуют в источнике.
- «SpotScore уже вычислен у реальных клубов» — формула и расчётный прототип готовы, для публичной оценки нужны наблюдения/аудит.
- «SQL выкачан в production» — нет; нужна миграция на тестовом Postgres и реальная интеграция с проектом.

## Перед production

1. Применить SQL в отдельной PostgreSQL 16 + PostGIS 3 среде с тестовым дампом; проверить `BEGIN/COMMIT`, FK, check constraints и `EXPLAIN` на spatial queries.
2. Реализовать RLS и явные права на редактирование по Claim Spot.
3. Добавить проверку полиморфных ссылок (assertions/media/opening hours), валидность Sport/Offer и owner-specific restrictions.
4. Добавить георучную верификацию, non-synthetic production seed и дедуп.
5. Ввести аудит и время изменения для каждого field assertion.
6. Обеспечить права на медиа и контент Telegram/VK.
7. Провести независимую калибровку SpotScore на реальных данных.
