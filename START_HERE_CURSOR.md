# START HERE — SpotMap для Cursor

**Цель первой рабочей итерации:** геопроверенная карта России для wakesurf + wakeboard cable с паспортами, фильтрами, маршрутами и trust-метаданными.

## Что читать по порядку

1. `AGENTS.md` — обязательные правила работы.
2. `docs/00_product/DECISIONS.md` — утверждённые пользователем продуктовые решения.
3. `docs/00_product/SpotMap_Product_Blueprint_v1.1.md` — канон.
4. `docs/01_architecture/SpotMap_Data_Model_v1.md` — модель сущностей.
5. `docs/02_passports/` — оба спортивных паспорта.
6. `docs/04_delivery/SpotMap_P0_Implementation_Backlog.md` и `Sprint_01_Foundation_Map.md`.
7. `docs/05_quality/SpotMap_QA_Report.md` — ограничения и риски.

## Никаких фиктивных мест

Исходные `80` записей — **staging candidates**, а не доказанный реестр действующих спотов. `6` cable-кандидатов — не полный перечень всех установок. У них нет подтверждённых координат; нельзя помещать их на публичную карту без геопроверки. Пример в `examples/synthetic/` предназначен только для контрактных тестов.

## Первый промпт

Откройте `docs/04_delivery/CURSOR_FIRST_TASK.md`, скопируйте содержимое в Agent (или сослаться на файл в контексте Cursor).

## Конец Sprint 01

Должны быть: согласованная архитектура, протестированная staging-БД, безопасный импорт с дедупликацией, map-API, первая карта с **только геопроверенными** точками и понятные отчёты проверки. При отсутствии подтверждённых координат карта показывает пустое состояние и staging-счётчик, но не синтетические пины.
