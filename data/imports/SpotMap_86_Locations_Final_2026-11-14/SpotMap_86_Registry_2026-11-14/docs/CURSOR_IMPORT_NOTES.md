# Импорт в Cursor / SpotMap — правила качества

Дата: 2026-11-14

1. Импортировать `data/staging/SpotMap_Master_86_2026-11-14.csv` **в staging, не в prod spots**.
2. CSV содержит 80 старых карточек + 6 дочерних электротяг. `legacy_row_id` исходной строки обязательно сохранить, не пересоздавать одинаковые записи.
3. Сначала entity-resolution / dedup. `entity_type=source_candidate` не равен географическому Spot.
4. При формировании слоёв карты использовать `map_eligible=true`, но подписывать точность «approximate». Для product-публикации дополнительно проверять `operation_status`.
5. `nested_only` не наносить отдельными физическими GPS, координаты наследуются от родительской площадки: UI показывает кратность установок.
6. `hold*`, `exclude_non_spot` не использовать как рабочие публичные места.
7. Углублённый source audit — столбцы `source_url`, `source_urls`, `researched_at`, `note`.
8. Для маршрутизации нельзя вести пользователя на ориентир дороги, площадку или здание, выдавая их за причал/въезд. Сделать отдельное поле `navigation_waypoint_verified_at` после ручной сверки.
9. Для A3 выбран `Исаковского 37к2с1`, прежние координаты Авиационной отвергнуты.
10. A4 точка на берегу требует оператора / спутниковой сверки; нельзя ставить pin в центре `ll` из URL.
11. A5: WAKESTYLE (boat Авиационная / pool Живописная / cable Крылатская) => одна группа бренда, три разных адреса.
12. A11: Polygon/track geometry кольца и GPS трёх установок требуются отдельно; road center ≠ cable location.

Ни одна точка не имеет `verified` в данном выпуске. Не увеличивай достоверность автоматически по числу десятичных знаков.
