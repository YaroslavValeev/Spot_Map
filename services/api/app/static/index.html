Фильтр и поиск ведут по карте. Паспорт открывается по клику на пин — без выдуманных рейтингов и координат.

Дисциплины

Показаны все дисциплины

Воздух — Ветер — Вода нет измерений

Вода ≠ воздух. Температура воды только из измерений, иначе «нет измерений».

Как читать карту

  • Проверенный GPS — паспорт с фактами
  • Черновик — координаты ещё уточняются
  • Кластер — несколько спотов рядом, увеличьте масштаб

Важно знать

  • Спот ≠ клуб ≠ лебёдка ≠ катер — у каждого свой паспорт
  • MVP сейчас: вейксерф и кабельный вейкборд
  • SpotScore и оценка ветра — только после проверки, иначе «не оценено»
  • «Записаться» ведёт на сайт клуба; клик ≠ подтверждённая запись
  1. Выберите дисциплину или найдите название сверху
  2. Кликните пин на карте
  3. Смотрите контакты, удобства и погоду в паспорте
